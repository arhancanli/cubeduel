# Code of Conduct

Short, because the substance is short.

## The standard

Be decent to people. Disagree about the code as much as you like — this project
argues with itself constantly in its own comments, and a well-made case that
something here is wrong is the most useful thing anyone can bring.

What is not welcome is aimed at people rather than work: harassment, personal
attacks, sexualised comments or imagery, publishing someone's private information,
or sustained disruption of a discussion.

Two things specific to this project:

**Criticise the claim, not the person.** The bar here is that nothing tells a
player something the code cannot support. If a claim in the README, a comment, or
the UI overstates what is actually true, saying so is contributing, not attacking —
and it will be treated that way.

**Do not test on other people.** Proof of concept work against ratings, accounts
or challenges belongs on your own, as
[SECURITY.md](SECURITY.md) sets out. Someone else's rating is not a test fixture.

## Scope

Applies in issues, pull requests, commit messages, discussions, and anywhere
someone is representing the project.

## Reporting

Report privately through
[GitHub Security Advisories](../../security/advisories/new), which is the private
channel this repository has. Include what happened and where.

Reports are handled by the maintainer. Depending on severity the response ranges
from a request to change behaviour, through editing or removing the content, to
blocking the account from the repository. Whoever reports something in good faith
will not have it held against them.

Where this document is silent, [the Contributor Covenant][cc] is a reasonable
guide to intent.

[cc]: https://www.contributor-covenant.org/version/2/1/code_of_conduct/
